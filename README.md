# Actividad Semanal 10

Formulario de registro construido con Angular y Bootstrap. Sus cinco campos son nombre, apellido, edad, correo y ciudad. Al guardar, los registros se conservan en el almacenamiento local del navegador.

Los avisos personalizados usan [SweetAlert2](https://sweetalert2.github.io/#download). Bootstrap se carga desde el CDN oficial mediante enlaces en `src/index.html`.

## Iniciar la aplicación

```bash
npm install
npm start
```

Abre `http://localhost:4200/` en el navegador.

## Compilar y probar

```bash
npm run build
npm test
```
